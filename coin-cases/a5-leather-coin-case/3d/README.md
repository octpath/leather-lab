# A5 Leather Coin Case — 3D Templates

裁断のケガキと、菱目打ち・丸錐・ホックの位置写しに使う平板型紙です。
底面はz=0の平面です。単位はmm、外形と穴中心は[PDF](../pdf/a5-leather-coin-case-pattern.pdf)と共通です。
通常は、以下の個別STLを1パーツずつ使います。

## ファイル

| ファイル | パーツ |
| --- | --- |
| [a-body-template.stl](a-body-template.stl) | A・本体 |
| [b-flap-liner-template.stl](b-flap-liner-template.stl) | B・かぶせ裏 |
| [c-left-gusset-template.stl](c-left-gusset-template.stl) | C・左マチ |
| [d-right-gusset-template.stl](d-right-gusset-template.stl) | D・右マチ |

必要な個別STLをスライサーへ読み込み、底面を下にして配置・印刷します。
参考用の[一括配置STL](a5-leather-coin-case-templates.stl)は、4個の独立した板を並べたものです。外接寸法は約113.97×201.97×3.4mmです。

| 設定 | 値 |
| --- | --- |
| プリンター・ノズル | Bambu Lab P1S・0.4mm |
| `plate_t` | 平板部2mm |
| `guide_d` | 1.1mm・丸い貫通穴 |
| `snap7_d` | 2.1mm |
| `snap12_d` | 3.6mm |
| `include_optional_flap_snap` | `true` |
| `engrave_attachment_lines` | `true` |
| `attachment_width` / `attachment_depth` | 0.6mm / 0.3mm |
| `ribs_enabled` / `rib_width` / `rib_height` | `true` / 1.6mm / 追加高さ1.4mm |
| `rib_inset` | 外縁からリブ外側まで6mm |
| `root_flare` / `root_height` | 根元の片側拡張0.3mm / 高さ0.3mm |
| `windows_enabled` / `window_radius` | `true` / 角R2mm |
| `frame_width` / `minimum_web` | 窓から外縁まで9mm以上 / 最小残り幅1.4mm |
| `tool_relief` | リブ部分だけ、工具穴の半径に0.8mmを加える |

全高は**2＋1.4＝3.4mm**です。補強寸法は試作値です。平板部2mm・ガイド穴1.1mmの実機試験済み基準と、今回のリブ付き形状の検証状況を分けます。

## 補強と肉抜き

[共通の補強規約](../../../docs/3d-reinforcement.md)に基づき、外周のリブと桟を連続させ、その間に窓を置いています。

| パーツ | 上面の骨格 | 貫通窓 |
| --- | --- | --- |
| A | 外周・中央の長手リブ・横桟・ホック周囲を接続 | 8個。幅18mm、長さ22／18／20／17mmを各2個 |
| B | 外周・長手リブ・ホック周囲を接続 | 省略。約74.97×30.49mmの小パーツで、ホックと穴列付近の接触面を残す |
| C・D | 外周・長手リブ・横桟を接続。左右は鏡像 | 各4個、18×5mm |

リブ幅は1.6mm、根元は片側0.3mm広げ、丸い端部・交差部でつなぎます。窓は全て角R2mmで、丸い工具穴と区別しています。
窓は材料量と骨格の配置を調整するためのもので、窓だけで強度が上がるとは扱いません。
設計上の最小残り幅は1.4mmです。実際の形状では、工具穴と外縁の間が最小1.45mm、窓と外縁の間が9.485mm以上、窓とリブの間が1.4mm以上あります。

外周のガイド穴列はリブの外側に置き、工具を近づけやすくしています。ホック周囲のリブには上面側の広い逃げを設け、**革に近い2mmの基準部では2.1／3.6mmを保っています**。上面の逃げは3.7／5.2mmです。
この逃げは肉抜き窓とは別の機能です。下面は、工具穴と貫通窓を除く接触面が同じz=0平面です。

- 菱目打ち・丸錐の位置写しには、どちらも1.1mmの丸穴を使います。革への本穴の大きさを示す値ではありません。
- Aの下端側は12号3.6mm、Aのかぶせ側とBは7号2.1mmです。Aのかぶせ側は位置を用意しているだけで、革への穴あけは任意です。
- Aの上面の浅い溝が、PDFの青い取付位置線です。穴列と中央のリブを避け、平板上と外縁に表示しています。
- 溝は上面だけにあり、革に当てる下面は平らです。上面の溝に合わせて外縁に目印を付け、型紙を外して線を結べます。
- 平板・貫通穴・上向きに開いた溝の形状なので、サポートを付けずに使う向きへ配置しています。材料と積層条件は使用する材料のP1Sプロファイルに合わせます。

## 使い方

1. 冷えた型紙の平面と穴の貫通を確認し、下面を革に当てます。
2. 外周をケガき、丸穴から縫い穴中心を軽く写します。Aの取付位置も写します。
3. 型紙を外し、革を裁断してから菱目打ち・丸錐で本穴をあけます。
4. ホック穴も、位置を写した後に型紙を外して7号または12号であけます。

## OpenSCAD

`part`を`A` / `B` / `C` / `D` / `layout`から選び、F6でレンダーしてSTLへ出力します。
初期表示は`A`です。`layout`は参考用の一括配置です。Aのかぶせ側の穴を型紙にも設けない場合は、`include_optional_flap_snap=false`にします。

板厚・穴径・リブ・窓・枠幅・最小残り幅・工具の逃げはパラメーターで調整できます。
窓の幅・長さは`window_scale_x` / `window_scale_y`、中心間隔は`window_spacing_scale`で調整します。パーツごとの窓と桟の配置は[reinforcement.json](../source/reinforcement.json)にあります。
Pythonから再生成するときは同JSONとOpenSCADの既定値を合わせます。食い違いや残り幅不足は出力前の検査で止まります。
裁断輪郭と穴中心の編集は[geometry.json](../source/geometry.json)で行い、[再生成手順](../source/README.md)に従います。

## スライスと実物の確認

CAD検査に加え、PrusaSlicer 2.7.2で個別4枚の押出経路を検査しています。検査した層で工具穴が開いていること、リブの押出領域がつながること、細いリブと元の穴際の肉がそれぞれ3本以上の経路で残ることを確認しています。
[スライス検査結果](../source/slice-qa.json)には対象STLのハッシュと検査層を記録しています。

| 経路検査に使った仮条件 | 設定 |
| --- | --- |
| 素材・温度 | PLA、ノズル210℃／ベッド60℃。経路検査用の仮値 |
| ノズル・積層高さ・線幅 | 0.4mm・0.2mm・指定幅0.42mm。ギャップ充填では可変幅あり |
| 壁数・上下充実層・充填率 | 3周・上下各5層・20% |
| 向き・サポート | 基準面を下、サポートなし |

[slice-check.ini](../source/slice-check.ini)は形状の経路検査専用で、P1Sの機械設定ではありません。検査用G-codeは配布しません。実際の印刷には、使用材料に合うP1Sプロファイルを使います。

この4枚のP1Sでの実機印刷・実革への使用・平面性とたわみは未確認です。
完全に冷却した後、翌日、数日〜1週間後を目安に、同じ置き方で浮き・がたつき・使用時のたわみを確認します。材料、積層条件、最大隙間、保管温度・荷重の有無を記録します。
