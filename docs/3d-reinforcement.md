# 3D型紙・革絞り治具の補強設計

リブ、肉抜き窓、外周枠を使うときの共通方針です。形状による補強、印刷時の反り、使用・保管後の変形を分けて確認します。ここに示す補強寸法の目安は試作の出発点であり、強度や平面性の保証値ではありません。

## 用途と守る寸法

| 用途 | 優先する条件 |
| --- | --- |
| ケガキ・穴位置写し用の薄い型紙 | 革に当たる面の平面性、裁断輪郭、工具の近づけやすさ |
| 革絞りの下型・成形用上枠 | 成形面、押さえ面、クランプ座、荷重が伝わる骨格 |
| 裁断・穴位置写し用の細い上枠 | 仕上がり輪郭と穴位置、開口、狭い部分の肉厚 |

- 補強を標準の設計検討に含める。不要な小パーツでは、省略する理由を作品の3D説明へ短く残す。全パーツに同じリブや窓を機械的に付けない。
- 薄型の位置写し用型紙は、P1S・0.4mmノズル・基本板厚2mm・ガイド穴の設計径1.1mmを引き継ぐ。2mmは平板部の厚さであり、リブを含む全高は別に記載する。
- 上記は位置写し用型紙の基準とする。クランプする治具の板厚・リブ・座面は、荷重と形状に合わせて別に決める。
- 確定した裁断輪郭・穴中心・ホック穴径を、補強や肉抜きの都合で動かさない。バネホック用の7号2.1mm・12号3.6mmと、位置写し用の1.1mmを分ける。
- 型紙の革に当たる平面と、治具の指定された挟持面・位置決め面を保つ。凸型の成形曲面は、意図された立体形状を保つ。

## リブの配置

- 平板型紙のリブは、原則として革に当たらない面へ設ける。ケガキ・裁断の基準となる外周を越えず、丸錐・菱目・ホックへの接近を妨げない。
- 外周の枠と、長い方向のたわみを受け持つリブを連続させる。必要に応じて横桟・格子を加え、クランプ座から支持部まで力が伝わる形にする。先端だけを厚くする孤立した補強を避ける。
- リブの根元・交差部は十分に接続し、可能なら小さなRや斜面でつなぐ。接触面やガイド穴へ丸みをはみ出させない。
- 左右の配置を可能な範囲で均等にし、一か所だけに高いリブや大きな厚肉部を集中させない。片面の補強でも冷却時の収縮差が生じ得るので、追加後の平面性を確認する。
- 薄型型紙の低いリブは、追加高さ1〜2mm程度から検討できる。幅は複数の連続した押出経路で構成できる値から検討し、初期目標を3本程度以上とする。寸法・本数だけで合格にせず、スライス結果と実物を確認する。
- リブがガイド穴の上を通る場合は、配置を迂回させるか、リブ部分だけに工具の逃げを設ける。革に近い基準部の設計径1.1mmと板厚2mmを保つ。上面側の広い逃げは、肉抜きとは区別して説明する。

## 肉抜き窓と残す骨格

- 肉抜きは軽量化・材料節約と骨格の配置を調整する手段として扱う。穴周囲の周回線が増えることと、部品全体の剛性・破壊強度が上がることを同一視しない。
- 外周枠、長手のリブ、横桟、穴周囲、クランプ座を先に確保し、その間の余剰部分へ窓を配置する。荷重が伝わる部分を窓で分断しない。
- 窓は細長い角丸長方形を基本とする。補強目的の丸い肉抜き穴や、工具穴に似た小穴の列は使わない。丸いガイド穴・金具穴・必要な工具の逃げは、それぞれの機能として残す。
- 鋭い内角、細長すぎる残り部分、窓端と穴が接近する配置を避ける。必要なら窓の数・大きさを減らし、リブや局所的な厚みを優先する。
- 貫通窓と非貫通ポケットを区別する。ポケットでは残る板厚と天井のブリッジを確認し、革に当たる面を変形・欠損させない。
- 最小肉厚は、窓と外周、窓同士、窓と工具穴、フレームの開口と穴の各組合せで確認する。円穴なら、穴中心から隣接する自由縁までの最短距離から穴半径を引いて残り幅を求める。
- 穴の周囲には連続した肉を残す。細部が一重壁になったり、スライサーで消えたりする場合は、窓の縮小・省略、リブ配置、工具の逃げを見直す。固定済みの穴径や穴中心の変更を解決策にしない。
- 細い裁断枠は、成形用の幅広枠とは別に評価する。機能上薄い箇所を残す場合は、その寸法・用途・未検証であることを記録し、断面の確認や小さな試験片を先に検討する。薄型型紙の板厚を、そのまま強くクランプする治具へ流用しない。

## 印刷条件とスライス確認

- 素材・ノズル・積層高さ・実際の線幅・壁数・上下の充実層・充填率・印刷向き・サポート条件を作品ごとに記録する。PLAの使用実績を、別素材や全作品の検証済み条件へ広げない。
- リブ幅や残り肉厚を、ノズル径×本数だけで確定しない。実際の線幅、隣り合う線の重なり、積層高さ、可変線幅などで経路は変わる。
- 充填率だけに頼らず、外周と穴周囲の壁、リブの接続、上下の厚さ、積層方向を確認する。必要な強度は実際の荷重方向で評価する。
- 革に当たる基準面を平らに印刷できる向きを優先し、サポートの痕をその面へ残さない。治具の曲面・アーチ・裏面ポケットでは、ブリッジやサポートが必要な場所を明示する。
- スライスの断面で、リブが平板へつながること、穴が貫通すること、必要な肉が残ること、孤立した部分や細い一重壁に依存していないことを確認する。スライス未確認なら確認済みと記載しない。
- 印刷時の反りには、形状に加えてベッドへの定着、材料に合った温度・冷却、取り外すタイミングも関係する。P1Sの使用材料に合うプロファイルを出発点とし、一律の高温・低冷却設定を追加しない。

## パラメーターと検証記録

- 基本板厚、リブの有無・幅・高さ、外周枠幅、肉抜きの有無・大きさ・間隔・角R、残す最小肉厚、工具の逃げを、編集元で独立に調整できるようにする。
- 強度確保に必要な最小肉厚を設計条件として明記し、条件違反を計算や出力時のチェックで検出する。暫定値と実機で確認済みの値を分ける。
- CADでは確定外形・穴中心・穴径の保持、最小肉厚、面の接続、閉じた形状、印刷向きと全高を確認する。リブ幅や窓を変えても機能寸法が変わらないようにする。
- 印刷後は完全に冷まして平らな基準面へ置き、浮き・がたつき・穴位置を確認する。曲げ、使用時のたわみ、破損、使用後に残る変形を区別して記録する。
- 経時変形の確認は、冷却後、翌日、数日〜1週間後を観察時点の目安とする。同じ置き方で最大隙間や写真を残し、保管温度・荷重の有無も記録する。許容値は作品の用途に合わせて決める。
- リブ付き・肉抜きありなら必ず反らない／強い、とは記載しない。必要に応じて無補強・リブのみ・リブと窓の組合せを、同じ材料・印刷条件で比較する。
- 作品の3D説明へ、補強の狙い、平板厚と全高、穴と窓の用途、採用した寸法、印刷条件、検証状況を短く残す。原則としてパーツ別STLと、パラメーターを持つ編集元を管理する。

## 根拠と適用範囲

上記は、ユーザーの工具・識別性の指定と、型紙・革絞り治具向けの設計方針をまとめたものです。補強の初期寸法、押出経路の初期目標、観察時点は、この用途の試作方針です。次の資料の数値をそのままP1Sの保証値として転用していません。

- [Prusa: Layers and perimeters](https://help.prusa3d.com/article/layers-and-perimeters_1748)：壁数、上下の充実層、線の重なりと薄壁厚さの関係。
- [OrcaSlicer: Walls](https://github.com/OrcaSlicer/OrcaSlicer/wiki/strength_settings_walls)：壁の設定と、一重の細い壁の扱い。
- [Prusa: Warping](https://help.prusa3d.com/article/warping_2011)：材料・温度差・冷却・形状と反りの関係。
