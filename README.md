## フォルダの方針

- 中分類の直下に、作品名のフォルダを作ります。
- 作品の通し番号は付けません。作品名で識別します。
- 各作品の入口は`README.md`です。概要、材料・寸法、製作手順、検証状況、関連ファイルへのリンクをまとめます。
- 改訂履歴はGitで管理し、通常は同じファイル名を更新します。比較用の別案は内容が分かる名前で残します。
- A・B・CやM1・M2・M3などのパーツ記号は、作品の通し番号とは別に使います。

| 作品フォルダ内 | 内容 |
| --- | --- |
| `README.md` | 作品の説明とファイル一覧 |
| `pdf/` | 原寸印刷用の型紙PDF |
| `3d/` | 印刷用STL、編集用OpenSCAD、治具の説明 |
| `source/` | PDF生成スクリプト、形状データ、必要な素材 |
| `images/` | プレビュー、製作・検証写真 |

必要なフォルダだけ作ります。未着手の作品フォルダや、配布ファイルをまとめただけのZIPは通常は置きません。

## 共通仕様

- バネホック用のハトメ抜きは7号（直径2.1mm）と12号（直径3.6mm）を使用します。各作品の型紙で割り当てを明記します。
- 3D型紙の位置写し用ガイド穴は、P1S・0.4mmノズル・基本板厚2mmで、設計径1.1mmを標準とします。革絞り用治具の板厚・補強は別途設計します。
- PDFはA4・100%で印刷し、各ページの確認線で倍率を確かめます。
- 日本語には日本語フォントを使います。

型紙の確定と、印刷・実革による試作確認の完了は、各作品のREADMEで分けて記録します。
