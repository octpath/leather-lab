# Lip Balm Case — Pattern Source

リップクリームケースの型紙（正本）の生成元です。

A4・100%印刷。各パーツページの50mm確認線で倍率を確認してください。PDFは表紙を含む全4ページです。

- A 前面：90×120mmの粗裁ち用。成形後の紙の窓型は省いています。切り揃えには[3DのM3裁断枠](../3d/m3-trimming-frame.stl)を使います。成形後の投影外形は、成形前の革の展開図ではありません。
- Aのホック：成形・乾燥後、M1の背面通路から革へ中心を軽く写します。型を外してハトメ抜き7号（直径2.1mm）で穴をあけ、ホックを取り付けます。成形後の中心は口元から12mm・左右中央です。粗裁ち上の左上から45×32mmは参考位置で、口元の基準は上端から20mmです。
- B 背面兼フラップ：Aと共通の穴座標を使用。フラップ100mmは余長を含み、ホック中心は仮です。穴はハトメ抜き12号（直径3.6mm）です。Aの成形後に83mmのリップを入れて位置と長さを合わせます。
- C Dカン留め：内幅15mm程度のDカンを仮定。14×42mm、短い先端側12mmを裏へ折り返します。先端側10mm程度を斜め漉きします。金具の線径・革厚に合わせ、折り返しと重ね穴を実物で合わせます。

## Cの穴と横縫い

Cの座標原点は短い漉き先端の左上です。穴はx=3,7,11mm、y=3,21,39mm。上端から12mmを基準に折り返すと、y=3mmの列がy=21mmの列に重なり、完成時には横縫い2列になります。下側y=39mmの列は長い側だけを通ります。

B上ではCの取付け長方形の上端を口元高さに揃えます。横縫いは口元から9mmと27mm。各列はx=-8,-4,0,4,8mm、すべて4mm間隔です。

- x=-4,0,4mmはCとBを重ねて縫う穴。
- x=-8,8mmはCの外側1mmに位置し、Bだけに丸錐であける始点・終点です。Cにはあけません。
- PDFとSVGの黒い丸印は丸錐穴の位置記号で、実際の穴径の指定ではありません。

## 共通条件

- 裁断線は濃灰の実線0.6pt、縫いガイドは茶橙の実線0.35pt、穴中心は同色の表示径0.4mmの点です。取付位置・折り目安は青の一点鎖線0.5pt（4 2 1 2）です。点の表示径は革の穴径ではありません。
- 革厚1.0-1.5mm、裁断線から穴中心まで3mm。
- 菱目打ちの中心間4mm。底の半円は弧長ではなく弦長4mmで設計。
- 縫い線の底半径は12.784906443mm、裁断線の半径は15.784906443mm。
- A成形後外形は幅31.569812886×高さ66.784906443mm。B全高166.784906443mm。
- 有効収納深さ約55mmは目標値です。実際の革の伸縮、底への座り方、金具とフラップを初回試作で確認してください。

## 再生成

このフォルダでPython 3を使って実行します。依存パッケージは`requirements.txt`に記載しています。

```sh
python -m pip install -r requirements.txt
python build_pattern.py
```

PDFは隣の`pdf/`へ出力します。SVGは原寸の2D参照形状です。ホック中心・粗裁ち基準等はPDFと`geometry.json`を優先してください。

このフォルダの成形寸法には、PDF検討時の参考値が含まれます。現行の3D治具の寸法・補強・背面の位置写し通路は、[OpenSCAD原稿](../3d/lip-balm-tools.scad)と[3Dの説明](../3d/README.md)を参照してください。

`assets/NotoSansJP-Regular.ttf`はNoto Sans JP（SIL Open Font License 1.1）です。`assets/OFL.txt`を参照してください。

## 3Dの再確認とプレビュー

OpenSCADから必要なSTLを再出力してから実行します。

```sh
python -m pip install -r requirements-3d.txt
python check_3d_tools.py
python build_3d_previews.py
```

`3d-qa.json`はM1の背面通路、M3の35穴・縫い代・スリット・工具の進入空間を実メッシュで確認した結果です。CAD上の検証と、スライス・実機印刷による強度確認は別です。
