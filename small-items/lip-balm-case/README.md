# Lip Balm Case

英語正式名：**Lip Balm Case**／日本語名：**リップクリームケース**

革絞りした前面A、背面兼フラップB、Dカン留めCで作るリップクリームケースです。AとBの左右・底を縫い合わせ、フラップをバネホックで留めます。前面の底は丸く成形します。

## 作り方の流れ

1. Aを90×120で粗裁ちし、口元と中心線を目印にM1へ合わせます。ホックはまだ取り付けません。
2. 湿らせたAをM1・M2で成形し、乾燥させます。
3. M1背面の通路から、本体側ホック中心（口元から12・左右中央）を軽く写します。
4. M2をM3へ交換し、幅1.5のスリットの内側に沿って裁断線をケガき、35穴の中心を写します。左右は接続部で途切れるため、型を外して定規でつなぎます。底の半円は連続スリットです。
5. 型を外してAを裁断・穴あけし、7号（2.1）のホックを取り付けます。
6. Cの先端を斜め漉きし、短く折り返してDカンを通します。取付け長方形の上端をAの口元へ揃え、Bへ横2列で縫い付けます。各列の両端はBだけに丸錐で穴をあけます。その後、AとBを縫い合わせます。
7. 最長のリップを入れてB側ホックの最終位置を合わせ、12号（3.6）で穴をあけて取り付けます。

口元の1.1mm穴は裁断位置の目印です。革を貫通させる用途ではありません。位置写し用の型紙の上から、ハトメ抜きや菱目打ちを打ち込みません。

## 検証状況

- PDFの裁断形状・縫い穴配置は確定済みです。Bのフラップ側ホック中心は、成形後に合わせるための仮位置です。
- STLはデータ上の寸法、穴径・中心位置、閉じた形状を確認済みです。
- M1は成形後にホック中心を写す背面通路付きです。M3は外枠・幅1.5の裁断スリットを追加し、アーチを口元より上へ移しました。裁断線と35穴の位置は引き継いでいます。詳細は[3Dの説明](3d/README.md)を参照してください。
- 6部品を使った実機印刷・革絞りによる確認はこれからです。凸型の寸法、革厚の逃げ、新しい位置写し通路とスリットは初回試作で確認します。
- 位置写し穴の標準径1.1mmは、別途実施したP1S・0.4mmノズル・板厚2mmの試験片の結果を採用しています。

PDFはA4・100%で印刷し、各パーツページの50mm確認線で倍率を確認してください。
